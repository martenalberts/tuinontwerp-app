# Tuinontwerp achtertuin (app)

Installeerbare web-app (PWA) met de stukken van het vastgestelde tuinontwerp: ontwerpdossier, plattegrond, 3D-model, legplan 40 × 80 en sfeerbeelden. Werkt na het eerste bezoek ook zonder internet.

Openen: https://martenalberts.github.io/tuinontwerp-app/

Installeren: open de link in Chrome of Edge en kies "App installeren", of op iPhone in Safari "Zet op beginscherm".

Deze map wordt gemaakt door `Rekenscripts/pwa_bouw.py` in het (privé) project Tuinontwerp. Pas de pagina's daar aan, bouw opnieuw en push deze map.
